# MCX Commodity Trading Engine (`mcx-comm`)

Automated live trading engine for MCX Gold Futures (starting with **GOLDPETAL**) via Zerodha Kite Connect, translating the `gold.pine` PineScript strategy to production Python code.

---

## Strategy Summary

* **Strategy**: Gold Trend Filter (PineScript v4)
* **Timeframe**: 1 Hour (`60minute`)
* **Candle Type**: Heikin-Ashi (calculated from 1H OHLC)
* **Entry Channel**: 20 periods Donchian upper break
* **Exit Channel**: 10 periods Donchian lower break
* **Trend Filter**: EMA(200) on Heikin-Ashi close
* **Risk & Stops**:
  * Trailing SL: `2.0 × ATR(20)`
  * Take Profit: `4.0 × ATR(20)`
  * Partial TP: Disabled
  * Skip Opening Candles: First 2 candles of each session (09:00, 10:00) skipped
* **Position Sizing**: ATR-based dynamic risk sizing
  $$\text{lots} = \left\lfloor \frac{\text{Capital} \times \text{Base Risk \%}}{\text{ATR} \times \text{ATR Multiplier} \times \text{Lot Multiplier}} \right\rfloor$$
  * Capital = ₹2,00,000
  * Base Risk = 2.0%
  * ATR Multiplier = 1.5
  * Lot Multiplier = 1 (1g per GOLDPETAL lot)

---

## Key Features

1. **Token Reuse**: Reuses `KITE_ACCESS_TOKEN` generated by `nifty-strike-engine` without re-authenticating.
2. **Contract Auto-Selection**:
   * Automatically picks the nearest next-month futures contract (e.g., `GOLDPETAL26DECFUT`).
   * If a position is already open in the exchange/state, tracks that specific contract until exit.
3. **Crash Recovery & Reconciliation**:
   * State stored in `data/state.json`.
   * On startup, reconciles state with active broker positions and restores open trades & stops.
4. **Discord Webhook Alerts**:
   * Rich embed notifications for BUY entries, SELL entries, Exits (Channel Stop, Trailing SL, EOD), morning briefing, and EOD summary.
5. **MCX Market Hours Guard**:
   * Active market hours: 09:00 to 23:30 IST.
   * Entry cutoff: 22:00 IST.
   * EOD Force Exit: 23:25 IST.
   * Lightweight hourly REST polling (no WebSocket connection overhead or stall issues).

## Configuration

### 1. Environment Variables (`.env`)

Create `.env` from `.env.example`:
```bash
cp .env.example .env
```

```env
KITE_API_KEY=your_api_key_here
KITE_API_SECRET=your_api_secret_here

# Access token is automatically read from nifty-strike-engine:
NSE_ENV_PATH=D:/Workspace/nifty-strike-engine/.env

# Discord webhook URL:
DISCORD_WEBHOOK_URL=https://discord.com/api/webhooks/...

# Live order flag (false = paper/simulation, true = live MCX order placement)
LIVE_ORDER_PLACEMENT=false
```

### 2. Strategy Parameters (`config/settings.yml`)

Parameters such as `capital`, `base_risk_pct`, channel lengths, and timings can be configured directly in `config/settings.yml`.

```bash
pip install -r requirements.txt

pytest tests/ -v

# Run engine
python main.py
```

## Raspberry Pi Deployment

1. Clone or sync this repository to `/home/pi/mcx-comm`.
2. Run the automated Pi setup script:
   ```bash
   chmod +x deploy/setup_pi.sh
   ./deploy/setup_pi.sh
   ```
3. Configure `.env` with your API key, Discord webhook, and `NSE_ENV_PATH` pointing to the Pi location of `nifty-strike-engine/.env`.
4. Start and enable service:
   ```bash
   sudo systemctl start mcx-comm
   sudo systemctl status mcx-comm
   sudo journalctl -u mcx-comm -f
   ```
